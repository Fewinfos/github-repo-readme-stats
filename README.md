# 📊 GitHub Repository Stats Widget

An open-source, fully client-side tool that visualizes **real-time GitHub repository statistics** in an interactive and customizable format — perfect for developers, open-source maintainers, and portfolio builders.

---

## ⭐ Repository Ranking System

The widget now includes an **intelligent ranking system** that evaluates repositories based on multiple weighted metrics and assigns a letter grade (**S, A, B, C, D**) with a numerical score.

The ranking badge appears automatically in the widget header, providing a quick overview of repository quality, activity, and community engagement.

---

### ⚙️ How Ranking Works

The ranking algorithm analyzes repositories across three major categories:

---

#### 📊 Popularity Metrics (30%)

Measures overall community interest and repository adoption.

- **Stars (15%)**  
  Logarithmic scale that measures repository popularity and visibility.

- **Forks (8%)**  
  Indicates how frequently the repository is reused or extended.

- **Watchers (7%)**  
  Shows active monitoring and community engagement.

---

#### 🔥 Activity Metrics (30%)

Tracks development momentum and repository freshness.

- **Commit Activity (12%)**  
  Evaluates recent development consistency and activity levels.

- **Release Cadence (8%)**  
  Measures frequency and regularity of project releases.

- **Recent Updates (10%)**  
  Determines how recently the repository was updated.

---

#### 💚 Community Health (40%)

Analyzes collaboration quality and repository maintenance.

- **PR Merge Rate (10%)**  
  Percentage of pull requests successfully merged.

- **Issue Close Rate (10%)**  
  Measures efficiency in resolving issues.

- **Contributor Diversity (8%)**  
  Active vs total contributor ratio.

- **Discussion Activity (7%)**  
  Average comments and interaction per issue/PR.

- **Code Quality (5%)**  
  Commit message quality and repository consistency.

---

### 🏆 Ranking Tiers

| Tier | Score Range | Badge Color | Description |
|------|-------------|-------------|-------------|
| **S** | 90-100 | 🟡 Gold | Exceptional — Top-tier project with outstanding metrics |
| **A** | 75-89 | 🟢 Green | Excellent — Highly active and well-maintained |
| **B** | 60-74 | 🔵 Blue | Good — Solid project with healthy metrics |
| **C** | 45-59 | 🟠 Orange | Fair — Room for improvement in some areas |
| **D** | 0-44 | 🔴 Red | Needs Attention — Multiple areas need improvement |

The ranking badge appears automatically in the widget header, showing both the tier letter and numerical score.

## 🚀 Quick Start

Embed the widget into your GitHub README:

```markdown
![Repository Stats](https://github-repo-readme-stats.vercel.app/api/?username=YOUR_USERNAME&repo=YOUR_REPO)
```

Replace:

- `YOUR_USERNAME` → Your GitHub username
- `YOUR_REPO` → Your repository name

## 📌 Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `username` | GitHub username | ✅ |
| `repo` | Repository name | ✅ |
